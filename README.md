# 장미와 펌프

숫자 뒤에 숨은 세상 1편 「나이팅게일과 데이터 시각화」의 부록 앱입니다. 나이팅게일이 정리한 크림 전쟁 영국군의 월별 사망자로 직접 그린 장미 도표(표↔그림 비교, 두 해 비교, 면적과 반지름 방식 비교), 존 스노의 1854년 소호 콜레라 지도(사망자 578곳·펌프 13곳·거리, 가장 가까운 펌프로 색칠)와 날짜별 발병·사망 그래프로 본 "펌프 손잡이의 진실", 세로축 시작·건수와 비율·면적 착시 세 가지 그래프 읽기 실험, 오늘의 체크리스트와 세 문항 연습을 담았습니다. 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

## 자료
- R 패키지 HistData(Michael Friendly 외)의 Nightingale, Snow.deaths, Snow.pumps, Snow.streets, Snow.dates 데이터를 Rdatasets(vincentarelbundock/Rdatasets)에서 받아 그대로 넣었습니다.
- "가장 가까운 펌프"는 앱이 직선거리로 계산한 값입니다(Broad St 358/578). 스노는 실제 걷는 거리와 이웃 조사로 판단했습니다.
- 그래프 읽기의 A·B 제품 값과 두 도시 숫자는 설명을 위한 예시입니다.
- 아무것도 저장하거나 보내지 않습니다.
